## FLEX Disk Wrangler 1.0.0, release candidate 1

The first release of FLEX Disk Wrangler, a program for disc images of **TSC FLEX**, the disc operating system of 6800
(FLEX 2) and 6809 (FLEX 9) computers. It is the third Disk Wrangler, beside Acorn Disk Wrangler and CP/M Disk
Wrangler, built on the same DiskWranglerCore library (version 1.1.1).

This is a **release candidate**: please try it on copies of your discs, and say how the discs it has changed behave
under real FLEX (an emulator or a real machine). That is the one thing the tests can't show.

### What it does
- **Reads** raw FLEX images (`.dsk`) in whatever geometry the disc's System Information Record gives: lists the
  files, views them (FLEX text with its space compression expanded, or hex), and copies them out by Extract, drag and
  drop or Copy. Files come out exactly as stored (CR line ends, space compression kept), so out and back in gives the
  same file; a random-access file comes out without its sector map.
- **Writes** them: add files (Add files, drop, Paste), rename, protect (write, delete, read, catalogue) and delete
  files, and change the volume name and number.
- **Changes are made the way FLEX makes them.** Where a new file's entry goes, which sectors it takes, how the
  directory grows, what deleting leaves, a random-access file's sector map and the System Information Record after
  each change were read from FLEX itself (FLEX 2.0 and three FLEX 9s). As in FLEX, a protected file can't be deleted,
  renamed or replaced (take the protection off in Properties first), and an empty file can't be stored.
- **New disc images** in the shapes of real FLEX discs (35 or 40 tracks of 10, 18, 20 or 36 sectors, and 8-inch
  77 x 15), laid out as FLEX's NEWDISK lays a disc out.
- **The boot loader.** FLEX's boot loader is TSC's own code, so the program carries none: a new disc works under FLEX
  but doesn't start it. To make a disc that starts FLEX, copy the loader from a FLEX system disc you have (New disc
  image, or Tools > Copy boot loader from), put FLEX.SYS on the disc and link the loader to it (Tools > Link boot
  loader to file), as FLEX's LINK command does.
- **Checks** a disc's directory, file chains and free chain (Tools > Check disc). A disc with errors, or whose image
  file isn't the size its System Information Record gives, opens read-only. Every save is checked, and the saved copy
  is read back and checked before it replaces the original (with a `.bak` copy if you want one).
- **OS-9 and UniFLEX discs** are recognised and named, not opened.
- **Exchanges files** with the other Disk Wranglers and other programs by drag and drop and Copy / Paste (the
  retro-files format): a file from another FLEX disc keeps its protection and date, and a random-access file becomes
  random-access again with a new map.
- **Command-line program `flexdw`**, installed beside the program (Windows: beside the `.exe`; macOS: inside the app,
  `Contents/MacOS/flexdw`; Linux: `/usr/bin/flexdw` from the `.deb`, or the AppImage started under the name `flexdw`):
  info, check, ls, get, put, rm, mv, attr, title, copy and new (`flexdw new --list` for the shapes), with `--json`,
  exit codes and `--dry-run`, as the other Disk Wranglers' console programs.

### Known limits
- Only raw images (`.dsk`). FLEX discs in ImageDisk or DSK files, and images whose track 0 is single density with
  fewer sectors than the other tracks, aren't read yet.
- `flexdw` can't copy a boot loader or set the volume number (the window can; `flexdw title` sets the volume name).
- Deleted files can't be recovered yet.
- None of the builds is signed: Windows and macOS warn the first time you start it.

### Building from source
The shared code is the DiskWranglerCore library (version 1.1.1), a git submodule in `core/`. Clone with
`git clone --recurse-submodules`, or run `git submodule update --init` after cloning. GitHub's "Download ZIP" and
"Source code" archives leave `core/` empty; use the complete source archive attached to this release.

### Downloads
Windows installer and zip, macOS disk image, Linux AppImage and .deb, each for Qt 6, with `flexdw` in each; and the
complete source (`...-source.tar.gz`, with `core/`).
