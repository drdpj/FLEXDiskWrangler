# Testing FLEX Disk Wrangler

    tests/run_all.sh <build dir> [<the sample FLEX discs' folder> [<the UniFLEX sample discs' folder>]]

builds everything with whichever `qmake` is first on the path and ends `ALL PASSED` or `SOME TESTS FAILED`. It needs
Python 3. Without the second argument the sample discs aren't checked; with it, every sample is read (copies, in a
temporary folder). The third is the owner's UniFLEX collection (`testdata/UniFLEX`, its 37 `.dsk` images; the two
UniFLEX discs among the FLEX samples, `C012_1` and `C014`, come with the second).

| Test | What it checks |
| --- | --- |
| core tests | DiskWranglerCore's own tests (settings, transfer, UI helpers, containers and saving, the Importer, the command line, the Volume interface, the DFS and FAT modules), built from the pinned `core/` |
| `tests/flex_check.py make` | makes the synthetic discs everything else uses (deterministic): `basic.dsk` (text, binary, random, protected, deleted, dated and undated files), `big.dsk` (45 files over 5 directory sectors, 40 x 36), `empty.dsk` (77 x 15), `full.dsk` (its directory full: the next file makes it grow), `frag.dsk` (a free chain in which no two sectors follow each other), `random.dsk` (random files of 300 and 200 data sectors to copy), five damaged discs (`bad-freeloop`, `bad-freecount`, `bad-chain`, `bad-crosslink`, `bad-dirloop`), `short.dsk` (a file shorter than its SIR says), `short0.dsk` (77 x 26 with a single-density track 0 of 15 sectors stored at its own size, its 11 directory sectors full), `pad0.dsk` (35 x 18, track 0 of 10 padded to 18, as the sample EFORTH), `cut.dsk` (a full track 0 in a file whose size is a short track 0's: not taken for one), an OS-9 and a UniFLEX disc, and noise |
| `uniflex_check.py make` | the synthetic UniFLEX discs, in the same folder (deterministic): `uf-basic.dsk` (600 blocks and 16 of swap: CR text with TABs, a binary, a nested tree, a hard link, a file with blocks never written, one reaching a double indirect block, a 14-character name, a character and a block device, an empty file), `uf-many.dsk` (a directory of 340 files, its map reaching an indirect block), `uf-odd.dsk` (a name with a newline, one with a space), seven damaged discs (`uf-bad-dup`, `uf-bad-freecount`, `uf-bad-links`, `uf-bad-freefdn`, `uf-bad-chain`, `uf-bad-map`, `uf-noroot`) and `uf-short.dsk` (cut short) |
| `voltest` | detection by tiers on every synthetic disc; the FLEX volume through `dw::fs::Volume` (names, sizes, attributes, dates, contents, the retro-files family); every kind of change inside `Disc::transact`, each leaving a disc that checks clean and a faithful `reload()`; what FLEX refuses, each leaving the staged disc exactly as it was; a random file copied and read back; the directory growing; the checked save read back; Save As byte for byte; new discs of every preset (a short track 0 padded, the directory to its last sector); a short track 0 stored at its own size (the sectors in range, the directory growing onto track 1, the save and Save As in the same layout), padded, and only looking short (`cut.dsk`, read-only); a boot loader read from a disc, copied and linked; `short0.dsk` in an ImageDisk file with its single-density track 0 (detection, the same disc as the raw file, a change and the save into the ImageDisk file keeping every track's density, Save As extended DSK and convert to raw, a raw image refused as ImageDisk and nothing as TeleDisk); each damaged disc's fault named and the disc read-only, and `short.dsk` read-only for its size; the name rules; and every sample disc (17 FLEX discs open, the 3 damaged ones fail their check and are read-only, the 2 OS-9 ones are named, the 3 UniFLEX ones open read-only with their faults; on a copy of each healthy FLEX one a file added and one deleted, saved and read back). UniFLEX: `uf-basic.dsk` through the volume (the tree, every kind of file, holes, the indirect blocks, devices, the access bits, owner, links and times, retro-files); on a copy, every kind of change inside `Disc::transact` (a file, an empty file, a directory, a file with its access and owner, renames in place, a file moved, a directory renamed, a directory moved and back (its parent's links), access and owner, the SIR's names and number, a tree deleted, a file replaced keeping its fdn's access and owner), each leaving a disc that checks clean and a faithful reload, the time of the change on what was written; what is refused (a name that exists, a file over a directory, a long name, a directory into itself, `/.badblocks`, a disc full, an owner out of range), each leaving the staged disc exactly as it was; the checked save read back; Save As byte for byte; each damaged disc's fault named; the name rules; and, with the third folder, every UniFLEX sample opened (writable exactly when healthy), reloaded faithfully, every readable file read |
| `guitest` | the window (offscreen): the menus in the family's order, what is enabled on a writable disc and greyed on a damaged one, the rows and their cells, View (FLEX text expanded), Extract (as stored, lower-case names, dated), Copy, Properties, Disc information, Check; on a copy of `basic.dsk`: Add files (an empty file refused), Rename, Properties, Volume name, Delete (a protected file refused), Save and open again; New disc image with a boot loader copied, Link boot loader, Copy boot loader; a UniFLEX disc (its pane alone with no tabs, the status, the tree's rows and cells, what is enabled, View with UniFLEX's text, Extract of a folder and a file with names as they are and the fdn's time, Disc information, Check, Properties; on a copy New directory, Add files into it, Rename in place, Save and open again; New disc image of a UniFLEX shape) and a damaged one (its errors in the status line, the broken file's reason); and discs it doesn't open |
| `tests/cli/run_cli.sh` | `flexdw`'s golden cases (`tests/cli/cases/`): info, check, ls and get; put, rm, mv, attr, title, copy (a random file) and new; what FLEX refuses (an empty file, a name that exists, protected files, a full disc, a map over 168 runs, a long volume name); a UniFLEX disc read (info, check, ls, get, attr) and two damaged or odd ones; a UniFLEX disc changed (mkdir, put, put over a file, mv in place and to another directory, a directory moved and renamed, attr, rm -r, title) and what is refused (a name that exists, a directory into itself, rm of a directory without -r, `/.badblocks`, any change to a damaged disc); on the synthetic discs, outputs and image hashes compared; `--update` rewrites them (only in a commit of its own that says why) |
| `ldd` | `flexdw` links neither QtGui nor QtWidgets |
| `flex_check.py compare` | the independent FLEX reader (written from `docs/disc-format.md`, not from the program) against `flexdw ls`, `get` and `check` on every synthetic and sample disc: names, sizes, attributes, dates, contents and whether the disc has errors (a disc that isn't FLEX: that flexdw doesn't read it as FLEX) |
| `flex_check.py writes` | `flexdw`'s changes against the independent model of how FLEX writes (`Fms`, written from `docs/disc-format.md`, "How FLEX writes", not from the program): a new disc of every preset against NEWDISK's layout (a double-density one with its short track 0), and scenarios of put, copy (random files), rm, mv, attr and title on the synthetic discs (`short0.dsk` and `pad0.dsk` too, and a new 77 x 52 disc filled past its 26 directory sectors) and three sample system discs (FLEX2_B, SYS900, FL2_0SWT), the image compared byte for byte after every step and every refusal matched |
| `uniflex_check.py compare` | the independent UniFLEX reader (written from `docs/uniflex-format.md`, not from the program) against `flexdw ls` (directory by directory), `get` and `check` on every synthetic UniFLEX disc: the tree, kinds, sizes, access, owners, links, fdns, times, device numbers, contents, which entries have problems, and whether the disc has errors |
| `uniflex_check.py writes` | the independent model of how UniFLEX writes (class `Kernel`: the kernel's routines and TSC's utilities, written from `docs/uniflex-format.md` "How UniFLEX writes", and checked there against UniFLEX running) against `flexdw`: scenarios of steps (files of every size to a double indirect block, directories made, moved files, directories renamed and moved (into themselves refused), a moved tree deleted, trees deleted, access, owners, replacing, the pack name, the fdn list running out and refilled, long free lists taken and written, a disc filled), on the synthetic discs and, with the third folder, copies of four healthy samples (two floppies, a Winchester); after every step the image is the model's byte for byte, a refused step changes nothing, and the result checks clean. Then each new-disc preset: `flexdw new` against `format_disc` (TSC's formatter, written from its source; the samples `dsdd8inch` and `dssd8inch` are its result byte for byte), and a file put and deleted on it |
| `containers_check.py` | FLEX and UniFLEX discs in ImageDisk and extended DSK files, with its own writer and reader of both (nothing from the program or the core). `make`: every synthetic and sample disc it knows the physical disc of laid out on it (sides, FM or MFM at TSC's rates, side 1 numbered on, sectors interleaved so that reading by position would fail; a padded double-density track 0 also as the single-density track it was, `-sd0`); `compare`: `flexdw` reads each as its raw disc (detection tier, listing, every file, the check); `writes`: on every healthy one, the same changes (put, rm, mv, title; UniFLEX mkdir, put, mv, title) on the raw disc and the container give the same disc, every track keeps its density, IDs and order, an ImageDisk file's untouched tracks byte for byte, and `convert` to ImageDisk, extended DSK and raw (a raw disc refused); `news`: `flexdw new` of every preset in ImageDisk, extended DSK and (uniform shapes only) DSK is the raw new disc on TSC's physical disc, and a file added the same. Third-party files (hxcfe, samdisk) are checked outside the repo: `design/test-scripts/containers/` |
| `uniflex_check.py samples` | the same on every UniFLEX sample, and each sample's check as `tests/uniflex_samples.txt` says (clean, or the faults it must name and no others) |

`tests/mkicon` writes the icon's PNGs (`icons/`); the `.ico` and `.icns` are made from them with Pillow, and
`icons/flexdiskwrangler.svg` renders the same as the PNGs (checked with Inkscape).
